# Level-1 Evaluation Kit reproduction package

Tracked declarations for independent reproduction of three kit-reference
Evaluation Kit corpora.

- Manifest: [`reproduction-manifest.json`](reproduction-manifest.json)
- Expected digests: [`expected/`](expected/)
- Outsider guide: [`../../docs/evaluation/INDEPENDENT_REPRODUCTION.md`](../../docs/evaluation/INDEPENDENT_REPRODUCTION.md)
- Canonical command: `../../scripts/reproduce-evaluation-evidence.sh --output <new-dir>`

Repository-relative `corpusPath` values are locators only. Content identity is
`eventsSha256` / `annotationsSha256`.

This package does not upload evidence and does not claim production efficacy.
